Gamepad Overlay input helper
============================
Lets OBS see the keys and mouse buttons you assigned to paddles, claw bumpers and other
extra buttons while you are playing in another window.

1. Install (one time): double-click install.bat   (needs Node.js)
2. Start: double-click start-helper.bat and leave the window open while you play or stream.
   It prints a "Helper code".
3. In the app, open "Global input helper", paste the code, then download the overlay file again.

Safety
- It only reports the exact keys and buttons you assigned to extra buttons.
- It only talks to this PC (127.0.0.1) and only to something that has your helper code.
- It never saves or sends what you type. Keep helper-code.txt private.
- If a game runs as administrator, start the helper as administrator too.
